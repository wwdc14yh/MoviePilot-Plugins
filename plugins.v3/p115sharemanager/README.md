## 流程

1. 每任务按 cron 表达式扫描监听路径 (默认 `0 */6 * * *`)；
2. 解析剧目录的 `{tmdbid-xxx}`，TMDB 查剧/季信息（宿主 `chain.tmdb_info` 优先，直连 API 兜底）；
3. 按完结检查规则判完结：
   - **按季完结分享**（默认）：某季 115 集号集合 == TMDB 该季已播集号集合即分享该季；
   - **按整剧完结分享**：整剧 `status=Ended` 且全部已播季都对上才整剧分享；
4. 完结后延迟分享（默认 48 小时，防洗板；锚点为 TMDB 最后一集播出日）；
5. 到期后复核 → 复制到 115 临时路径并按 TMDB 英文名重命名 → 等复制落地 → 创建分享 → 设长期 + 固定码 `wwdc` → `share_snap` 回读校验 → TG 频道推送 → 60 秒后删临时 → 立即删源文件夹（进回收站）。

失败不删任何东西（临时/源都保留），作业记 failed，可重试（分享已建时只重做推送及后续步骤）。

## 配置

- 115 登录：插件页面选平台扫码（web / iOS / Android / iPad / TV / 微信小程序），或手动粘贴 Cookie；
- 临时路径：默认 `/115分享暂存`；
- TG：频道 Chat ID；默认复用 MoviePilot 的 Bot，自带 Bot Token 时可发海报图；
- TMDB 兜底：宿主查不到时用直连 API（需 `tmdb_api_key`）。
